# Pocket GM — Soccer

Single-file React football-manager game (sibling of [baseball-gm](https://github.com/kyleb0226/baseball-gm)).
Pick your XI and formation, sim a two-division season with promotion/relegation, run the cup,
work the transfer market, develop youth, and build a dynasty.

**Play:** https://kyleb0226.github.io/soccer-gm/ — open on your phone in Safari and
**Share → Add to Home Screen** for an app-like icon. Offline-capable, saves to the browser.

No build step: React + Babel + Tailwind are vendored under `vendor/`.
